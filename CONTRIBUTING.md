# Участие в проекте

Спасибо, что хочешь помочь HMWT Гримуар.

## Лицензия вкладов

Проект распространяется по **AGPL-3.0-only**. Отправляя pull request, ты
соглашаешься, что твой вклад распространяется по той же лицензии.

Мы не требуем CLA. Вместо него используется **Developer Certificate of Origin
(DCO) 1.1**: каждый коммит должен содержать подпись:

```
Signed-off-by: Имя <email@example.com>
```

Подпись означает, что ты имеешь право передать этот код проекту и что он не
нарушает чужие права. Добавить её можно через `git commit -s`.

## Что можно предлагать

- исправления ошибок;
- улучшения интерфейса;
- новые справочники и импорт;
- оптимизацию;
- документацию и переводы.

## Что важно

- не добавляй код и ассеты без совместимой лицензии;
- не копируй чужие тексты, картинки, шрифты и интерфейсы;
- для новых зависимостей укажи лицензию;
- не используй название и логотип проекта в сторонних форках без разрешения
  (см. `TRADEMARKS.md`);
- крупные изменения лучше сначала обсудить в issue.

## Сборка

См. `README.md`. Перед PR собери `HMWT_MUI.csproj` и прогони
`RoomUiTests`.

## Релиз

Порядок, чтобы ничего не забыть (лицензия — обязательная часть релиза):

1. Подними версию в `Properties/AssemblyInfo.cs` и `Net/NetVersions.cs`,
   допиши строку в историю версий.
2. Прогони `RoomUiTests` — должно быть `ИТОГ: всё прошло`.
3. Собери установщик: `installer/build-installer.ps1`.
4. Собери архив исходников этой версии:
   `git archive --format=zip -o HMWT_WPF_<версия>_source.zip v<версия>`.
   В архив попадают `LICENSE` (AGPL-3.0-only), `NOTICE`, `SOURCE.txt`,
   `THIRD_PARTY_NOTICES.md`, `TRADEMARKS.md` — проверь, что они на месте.
5. Закоммить, поставь тег `v<версия>`, запушь `main` и тег.
6. В релиз на GitHub приложи **оба** файла: установщик и архив исходников.
   В описании укажи лицензию (AGPL-3.0-only) и что исходники этой версии —
   во вложении и по тегу.
